# PhD Supervisor Templates

Use these templates as compact working artifacts. Fill only the sections needed for the user's current task.

## Supervision Brief

```markdown

- Field/subfield:
- Degree output:
- Working topic:
- Current stage:
- Available materials:
- Next deadline:
- Main constraint:
- Target artifact for this session:
- Assumptions:
```

## Literature Matrix

```markdown
| Source | RQ/problem | Method/data | Main finding | Limitation | Relevance | Trust level |
|---|---|---|---|---|---|---|
```

Trust level should reflect source quality and relevance, not whether the source agrees with the student.
