# PhD Research Failure Modes

Use this file when progress feels stuck, too smooth, too broad, or intellectually fragile.

## Severity

- P0: Stop and repair before moving forward.
- P1: Repair this week before investing more effort.
- P2: Track and improve when convenient.

## Failure Mode Checklist

| Failure mode | Warning signs | Severity | Supervisor intervention |
|---|---|---|---|
| Topic drift | Each meeting changes the object of study; no stable RQ | P1 | Freeze a 2-week RQ version and define explicit out-of-scope items |
| Novelty as absence | "No one has studied X" is the whole contribution | P1 | Build a novelty map showing what existing clusters establish and what delta remains |
| Method-claim mismatch | Causal claims from descriptive data; general claims from narrow cases | P0 | Rewrite the claim or redesign the method |
| Literature hoarding | Endless reading with no synthesis, matrix, or decision | P1 | Require a literature matrix and a 1-page gap memo before more searching |
| Vibe citing | References look plausible but are not verified or do not support the sentence | P0 | Verify each citation; remove or replace unverifiable support |
| Confirmation corpus | Only supportive papers appear; no contradictions or null findings | P1 | Run a counter-evidence search and add dissenting sources to the matrix |
| Results shopping | Multiple analyses tried until one looks publishable | P0 | Reconstruct analysis history; mark exploratory analyses; define confirmatory follow-up |
| P-value theater | Statistical significance is reported without effect size, uncertainty, or assumptions | P1 | Add effect sizes, confidence intervals, assumption checks, and practical meaning |
| Benchmark overfitting | Model/method tuned to a single benchmark or leakage-prone split | P0 | Audit data splits, leakage, baselines, and external validation |
| Smooth AI output | Draft sounds polished but claims are unsupported or generic | P1 | Build a claim-evidence ledger before revising prose |
| Advisor-simulator sycophancy | The assistant praises weak ideas or avoids hard critique | P1 | Switch to review mode and require P0/P1/P2 risks |
| Endless revision loop | Revisions continue without quality delta or decision point | P2 | Define stopping criteria and move unresolved issues to limitations |
| Premature packaging | Formatting, abstract, or submission prep happens before core gates pass | P1 | Return to the failed gate: RQ, novelty, method, evidence, or writing spine |
| Ethics afterthought | Human subjects, sensitive data, or institutional risks are handled late | P0 | Pause data collection or publication planning until ethics path is clarified |
| Delegation overdose | Student cannot explain method, result, or contribution without the assistant | P0 | Require student-authored paraphrase, oral defense practice, and decision log |

## Recovery Protocol

1. Name the failure mode and severity.
2. State what evidence triggered the diagnosis.
3. Identify the earliest failed gate.
4. Propose the smallest repair artifact.
5. Set a stop condition and a next review date.
